# WorkMind AI

WorkMind AI 是一个面向企业办公场景的智能 Agent 平台，目标是将大模型能力接入到日常工作流中，打造一套可交互、可演示、可扩展的 AI 办公助手系统。

## 项目定位

该项目以“智能办公助手 + 多场景 AI 工作流”为核心，围绕企业日常办公场景构建了一套从前端交互到后端服务、从对话生成到流程编排的完整解决方案。项目重点体现了我在大模型应用落地、Agent 系统设计、RAG 知识库集成以及前后端协同开发方面的实践能力。

## 核心功能

- 智能对话助手：支持多角色对话体验，能够根据不同场景提供更贴近业务的回答。
- 任务型 Agent：通过 ReAct / Tool Calling 思路，让 Agent 能自主规划任务、调用工具并完成复杂操作。
- RAG 知识库：支持文档上传、分类管理、向量检索与基于知识库的流式问答。
- 工作流编排：内置周报生成、会议纪要、邮件润色、PRD 骨架等多个 AI 工作流，并支持人工审核环节。
- ERP 智能审批：支持自然语言填单、结构化表单解析，以及模拟多 Agent 审批流程。
- Prompt 调试与优化：提供 Prompt 单次测试、A/B 对比和模板管理能力，适合做模型提示词实验。
- 监控与成本观测：包含调用统计、Token 消耗、缓存命中率、成本分析等可观测能力。

## 技术栈

- 前端：Vue 3 + Vite + Element Plus + Pinia + Vue Router
- 后端：Node.js + Express
- AI 能力：LangChain + LangGraph
- 文档与检索：Chroma、PDF 解析、文本切分
- 通信方式：REST API + SSE（流式输出）

## 技术亮点

基于 Node.js + Vue 3 构建了一个面向企业办公场景的智能 Agent 平台，项目通过 LangChain + LangGraph 实现了 Agent 推理、工具调用与工作流编排，并结合 RAG 技术完成了文档知识库问答能力。系统支持多角色对话、任务型 Agent 执行、内容生成工作流、ERP 审批模拟、Prompt 调试与模型调用观测等功能，具备较完整的前后端交互与流式输出体验。

### 关键技术亮点

- 使用 LangGraph 实现 Agent 状态流转与工具调用循环，支持 ReAct 风格任务执行。
- 通过 SSE 实现前后端流式通信，支持实时输出推理过程、工具调用状态与生成结果。
- 集成 RAG 方案，实现文档上传、知识库构建、向量检索和基于上下文的问答。
- 构建了多种内置工作流模板，如周报生成、会议纪要、邮件润色、PRD 骨架生成，支持 Human-in-the-Loop 审核。
- 实现自然语言转结构化表单的 ERP 场景，模拟真实审批流程，体现了 LLM 在业务流程自动化中的落地能力。
- 设计了 Prompt 测试与 A/B 对比机制，支持提示词调优与实验验证。
- 引入 API 调用监控与成本统计模块，具备可观测性与资源使用控制能力。
